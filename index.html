PythonYOLOv11StreamlitTableauOpenAI APISlack
문제 정의
  • 미세한 공정 변화에도 불량이 발생하는데, 검사 결과와 공정 환경 데이터가 따로 관리되어 원인 파악 어려움

데이터

  • 이미지 단독 YOLO11n, 납고드름·밀림·핀홀 불량 16~19% 정상 오분류 확인

  • 성능 동등 모델 중 추가 파라미터 최소 FiLM + 요약통계 최종 선정

  • 센서와 라벨 과분리 데이터 특성 한계 명시, 현장 센서 데이터 재검증 개선 과제 도출

금속 식각 공정 엔드포인트 검증과 불량 감지 시스템

센서 3종(EV·RFM·OES)으로 이상 웨이퍼를 감지하는 Autoencoder, 배치 쏠림을 막은 균등 Test 20%에서 Precision 0.80 · Recall 0.74 · AUROC 0.91 검증

PythonAutoencoderSHAPStreamlitTableauOpenAI API
문제 정의
  • 식각 종점 판단 오류(Over·Under Etch)로 웨이퍼 가치 손실
  • 공정 종료 후에 웨이퍼 불량이 확인되어 수율이 떨어지는 문제 발생
  • 목표: 공정변수만으로 정상(Calibration)·이상(Fault)을 구분하는 FDC 모델 구축, 종점 검출(EPD) 구현 가능성 검증, 현장 대시보드

  • Lam 9600 TCP 금속 식각 웨이퍼 129장 (Calibration 108, Fault 21), Wise & Gallagher(1999) 데이터셋

  • 센서 오류 웨이퍼, EV 누락 웨이퍼(3122·3125번) 제외
  • RFM 시점 기준 최근접 EV 매칭 (보간 없음, 평균 매칭 거리 0.253초), OES 진행률 정규화 후 웨이퍼 단위 매칭

  • 임피던스 정합 상태 파생변수 5개 생성 (하부 RF 반사율, 상부 TCP 반사율, 전압/전류 비, 3차 고조파/기본파 전류 비, 공정 진행률)
