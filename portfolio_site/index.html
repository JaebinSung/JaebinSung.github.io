  • 기존 2D 방식: 사람 Box(+20% margin)와 물품 Box 화면상 겹침으로 소지 판단 (YOLOv8)
  • 깊이 정보 부재: 사람 뒤 책상 위 노트북 오탐, 앞뒤로 선 두 사람 중 소지자 구분 불가
  • 목표: 특수 장비 없이 일반 웹캠 1대로 사람과 물품이 같은 위치인지 판단
분석 · 모델링
  • YOLOv8 + ByteTrack 탐지·추적, MiDaS 단안 깊이 추정 병렬 수행, 연속 3프레임 유지 시 경고
  • 미터 환산 대신 깊이 비율: 두 깊이의 큰 값 ÷ 작은 값에서 1을 뺀 gap (깊이 2.0과 5.0이면 150%), 알 수 없는 스케일 계수 약분으로 사람 키 가정·보정 절차 불필요
  • 객체 대표 깊이: 박스 중앙 50% 영역 중앙값 (블루시그널 인턴 경험 반영, 빈 공간·배경 픽셀 영향 감소)
  • 판단 조건: 화면 겹침 30% 이상 + 깊이 gap 35% 이하, 물품이 여러 사람과 겹치면 깊이가 가장 비슷한 사람에게 배정
  • 2D·3D 판단 동시 계산, 2D만 경고였던 케이스는 파란 박스와 사유로 표시, 걸러진 건수 누적
  • 깊이 추정 3프레임마다 1회, 축소 이미지(폭 384) 추론으로 실시간 성능 확보
검증
  • 기하·판단 로직 별도 모듈 분리, 단위 테스트 19개 통과
  • 스케일 불변성 테스트: 장면 깊이에 0.02·1·57배를 곱해도 판단 동일
  • 핵심 시나리오: 화면 겹침 + 깊이 2.5배 차이 물품, 2D 경고 vs 깊이 방식 제외 확인
  • 실제 웹캠 실행: 손에 든 휴대폰 depth gap 9% 경고, CPU 환경 2.4 FPS
  • 경고 시 깊이 gap·겹침 비율 CSV 기록, 임계값 조정과 오탐 원인 분석 근거
한계
  • 비율 기준 특성상 카메라에서 멀수록 같은 %가 더 큰 실제 거리, 현장 영상으로 허용치 재설정 필요
  • 현장 성능 정량 검증 미실시, 조명·작은 물체·가림 상황 깊이 불안정
  • 다음 단계: 프레임 간 깊이 평활화, 현장 물품 Custom YOLO 학습
